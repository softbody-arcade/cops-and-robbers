# Remove BeamNG.Earth support

Design proposal for review, based on main at `aa5465626fc1354834870b25eb1aaa7bbf6502d0`.

CnR currently shares game-world positions on ordinary BeamMP maps. BeamNG.Earth gives each player a different coordinate origin, so CnR maintains a second network protocol and uses Earth services for routes and stations. Retire that integration end to end. Acceptance means a packaged, upgraded ordinary BeamMP server can run a chase, including practice and rejoin, with its usual routes, stations, rules and history. Earlier Earth traffic and weather proposals become historical research. Any future support requires a separate complete design, implementation and multiplayer verification in game.

## Decisions for the host

1. **What should happen if a host selects the old level?** One option is an explicit server-side refusal to activate CnR on `beamng_earth`, logged before registering gameplay handlers, sending player state or writing files. That retains a single map-ID check. Another is a documented host-side requirement to select an ordinary map before enabling the plugin, with no runtime detector. That puts responsibility for floating-origin positions, stale stations and Earth sky settings on whoever configures the host. Choose before implementation. Neither approach implies an automatic change to the server map. Keep support for ordinary third-party levels without a map whitelist.
2. **Where should a future live release go?** That is the host's own configuration, outside this repository. An actual host change, service restart or live rollout requires separate authorization.

## Existing installations and records

The host has never played on Earth and authorizes discarding Earth leaderboard data. The current `data/leaderboard.json` stores the level identifier on each run. Map filters, round history and player rankings derive from those rows. At upgrade, if any rows have exactly `map == "beamng_earth"`, a one-time offline cleanup may remove those rows. A board without matches needs no rewrite. Preserve every other run, its order and fields, including records with an unknown or missing map and ordinary runs by the same players. Retire the special spelling in `game.mapTitle`. No Earth history archive, migration or ongoing leaderboard filter is needed. Shared player colors, current build and backups, ordinary station files and host settings remain outside this cleanup.

Earth stations in `data/stations/beamng_earth.json` contain latitude/longitude. Keep that file byte-for-byte through installation, normal-map play and any approved host cutover. It has no general XYZ conversion without a reference frame. The ordinary parser would skip such rows and could later replace the file if run on that level. Account for that in the chosen unsupported-level policy. The tracked `data/stations/west_coast_usa.json` is separate from the server's mutable plugin data directory.

`make package` already builds a client ZIP and BeamMP server payload. `make install-local` overlays server files with rsync and can leave an earlier `cnr/geo.lua` behind. Scope upgrade cleanup to that known obsolete code file or a verified set of shipped code files. Test over an existing installation while preserving the installed config and data. The live deployment setup is outside the tracked repository.
