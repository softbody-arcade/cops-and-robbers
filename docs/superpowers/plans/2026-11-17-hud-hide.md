# HUD Hide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Hide button on the HUD's lobby card collapses it to a small "Cops and Robbers" tab at bottom centre; clicking the tab brings the card back, and the choice is saved per player.

**Architecture:**
- **Lua:** a new boolean `hudHidden` in `playerSettings.lua`. `hud.lua` copies it into the lobby block as `lobby.hudHidden`, so only the lobby payload carries it. The click goes through the existing `setting` action, which already saves `settings/cnr_settings.json` and pushes the HUD at once, so `copsAndRobbers.lua` needs no change.
- **Vue:** `HudLobby.vue` gets a Hide button that emits `hide`. A new `HudTab.vue` is the tab and emits `show`. `app.vue` shows the tab instead of the card when `hud.lobby.hudHidden` is true, and sends `{ action: "setting", key: "hudHidden", value }` for both.

**Tech Stack:** Lua (LuaJIT in game, Lua 5.x in tests), Vue 3 apps on the game's components. `make test`, `make vuecheck`, `make package`.

**Spec:** `docs/superpowers/specs/2026-11-17-hud-hide-design.md`. It is binding.

## Global Constraints

- **Code style:** no code comments, no emojis. Lua module table `M`, camelCase. Follow the surrounding files.
- **LuaJIT:** no `goto`, `//` or bit operators.
- **No version bump** and no `TODO.md` edit on the branch.
- **Key and default:** `hudHidden`, default `false`, saved with the other personal settings in `settings/cnr_settings.json`.
- **Only the lobby:** prep, the chase and the result show in full whatever the choice; a player's own practice round is a round.
- **Unchanged:** the notices still show (above the tab), an open Leaderboard or Host panel stays open, the Announcements app, the HUD's placement.
- **Tab:** bottom centre, reads "Cops and Robbers" with an up-pointing icon (`icons.arrowSmallUp`), built from the kit (`cnr-btn`, BngButton), `pointer-events: auto` only on the tab.

## Review Focus

1. **A broken settings file** (`hudHidden = "yes"`, `1`) loads as shown, never as hidden. Pinned in Task 1.
2. **The player's own practice round** (`active = true` with `lobby.practice` set) shows the full HUD with no lobby block, even when hidden. Pinned in Task 1.
3. **The result after a round** has no lobby block, so it shows in full; the lobby after it is hidden again. Pinned in Task 1 (client test).
4. **The Settings view** opens only from the full card: in a hidden lobby `settingsAllowed` is false, so a Settings card carried over from prep closes by the existing 1.5 s gap timer. Checked in Task 2 by reading `app.vue`.
5. **Notices** still render above the tab: `HudNotices` stays outside the lobby branch in `app.vue`. Checked in Task 2.

### Task 1: `hudHidden` setting and lobby payload

**Files:**

**Interfaces:**
- **Produces:** `playerSettings.load(decoded).hudHidden` (boolean, default false); `playerSettings.set(prefs, "hudHidden", v)` accepts booleans only. `hud.payload(...).lobby.hudHidden` is `true` only when `info.settings.hudHidden == true`, else `false`. `payload.settings` does not carry it.

- [ ] **Step 1: Write the failing tests**

`tests/test_player_settings.lua`, "the HUD is shown by default and hudHidden loads and sets as a boolean":
`load(nil).hudHidden == false`, `load({ hudHidden = true }).hudHidden == true`, `load({ hudHidden = "yes" }).hudHidden == false`, `load({ hudHidden = 1 }).hudHidden == false`; on `p = load(nil)`: `set(p, "hudHidden", true) == true` and `p.hudHidden == true`, again `== false`, `set(p, "hudHidden", "no") == false` leaves it true.

`tests/test_hud.lua`, "the lobby carries hudHidden and a round never does":
- `payload(new(), 0, { active = false, settings = { hudHidden = true } }).lobby.hudHidden == true`
- with `settings = {}` and with no `settings`: `lobby.hudHidden == false`
- `{ active = true, role = "runner", settings = { hudHidden = true }, lobby = { practice = "Reinder" } }`: `mode == "round"`, `lobby == nil`, `settings.hudHidden == nil`
- a result payload (`result = { untilT = 5 }`, `now = 0`) with `hudHidden = true`: `mode == "result"`, `lobby == nil`

`tests/test_client.lua`:
- "Hide on the lobby card is saved and the round shows in full": `bootClient()`, `fire("cnr_mode", {})`, `M.ui({ action = "setting", key = "hudHidden", value = true })`, `tick(0.2)`: `written["settings/cnr_settings.json"].hudHidden == true`, `hud().lobby.hudHidden == true`. `startCop(env)`: `hud().mode == "round"`, `hud().lobby == nil`. `fire("cnr_roundEnd", { reason = "cancelled", message = "Round cancelled" })`, `tick(0.2)`: `mode == "result"`. `tick(11)`: `mode == "lobby"`, `lobby.hudHidden == true`.
- "a hidden HUD stays hidden after a rejoin": `bootClient({ files = { ["settings/cnr_settings.json"] = { hudHidden = true } } })`, `fire("cnr_mode", {})`, `tick(0.2)`: `hud().lobby.hudHidden == true`.
