# Cops and Robbers: agent rules

- `TODO.md` is the shared ledger for every agent and worktree. Edit it only on main, in the main checkout; from a worktree, read it with `git show main:TODO.md`.
- Exception: an issue found on a branch about that branch's own unmerged code goes under Issues in the branch's `TODO.md` and reaches main with the merge. Anything else you find goes into main's `TODO.md`.
- When work starts, move its line from Ideas to In progress on main (with the branch, or "design"), keep it current as the work moves, and delete it once the work is merged and checked.
