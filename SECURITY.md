# Security

Please report security problems privately, not in a public issue.

Use GitHub's **Report a vulnerability** button on this repository's Security tab. It opens a private advisory that only the maintainers can see. Include what an attacker could do, how to reproduce it, and which version you tested.

If the button isn't there (for example while the repository is private), open an issue titled **"Security contact request"** that says only that you have a security report. Put no details in it. The maintainer will reply with a private way to send the report.

Security reports could cover, for example:
- a way for a player to crash or take over a server through the mod
- a way to run code on another player's game
- a leak of private data

The maintainer will answer as soon as possible, agree a fix and a release with you, and credit you unless you prefer otherwise.

Only the latest release is supported.
